sem-shell

An interactive shell over a small in-memory file system of SemText documents — the <sem-terminal> core configured with the bundled semtext-demo plugin (see src/terminal/PLUGINS.md). Try ls -l, cat demo/welcome.html, semtext outline demo/token-rotation.html, open demo/welcome.html. Arrows recall history; Ctrl+L clears; help lists everything. On boot the shell also demonstrates the CDN rule: a second plugin from an https:// URL with no integrity hash is refused before any request.
